\# Shreyanshu Pratik — Developer Portfolio



A modern, responsive personal portfolio website built with \*\*React, Vite, Tailwind CSS and Framer Motion\*\*.



\## About Me



Hi, I'm \*\*Shreyanshu Pratik\*\*, an Information Technology student and aspiring Software Developer passionate about building modern web applications and creating clean, responsive and user-friendly digital experiences.



This portfolio showcases my technical skills, academic journey, resume and professional profile.



\## Features



\- Modern dark-themed interface

\- Fully responsive design

\- React + Vite

\- Tailwind CSS

\- Framer Motion animations

\- Professional profile avatar

\- Resume download

\- Technical skills showcase

\- Education section

\- Contact section

\- GitHub integration

\- Vercel deployment



\## Tech Stack



\- React.js
